# School Management System

## Overview
This is a Python-based school management system built using object-oriented programming.

## Features
- Student registration
- Teacher management
- Course enrollment
- Attendance tracking
- GPA calculation
- Report generation

## Technologies Used
- Python
- Object-Oriented Programming

## Concepts Demonstrated
- Inheritance
- Encapsulation
- Polymorphism
- Data Structures

## How to Run

```bash
python school_management.py
```
